# 🍿 КіноМатч

Веб-сервіс у стилі Tinder, щоб компанія друзів швидко обрала фільм для спільного перегляду.

1. Той, хто створює кімнату, **обирає один чи кілька жанрів** (або «будь-які»).
2. Сервер добирає 20 фільмів під ці жанри, а друзі заходять за кодом кімнати.
3. Усі свайпають одну й ту саму колоду: вправо «хочу», вліво «пас».
4. Рейтинг оновлюється наживо; якщо фільм сподобався всім — **МАТЧ!**

## Швидкий старт

```bash
npm install
npm start
```

Відкрийте http://localhost:3000. Потрібен Node.js 18+.

## Звідки беруться фільми (OMDb)

- У `data/imdb-ids.json` лежить список ~180 відомих фільмів (IMDb ID). Редагуйте його, щоб змінити каталог.
- При першому запуску сервер через OMDb API завантажує для них постер, жанри, сюжет і рейтинг IMDb
  (близько 180 запитів, ліміт безкоштовного ключа — 1000 на день) і зберігає у `data/omdb-cache.json`,
  тож наступні запуски не витрачають ліміт. Перші секунди після першого старту список жанрів може завантажуватись довше.
- Жанри з OMDb перекладаються українською (`GENRE_UA` у `server.js`). Фільм потрапляє в колоду, якщо має хоча б один із обраних жанрів;
  фільми з більшою кількістю збігів мають пріоритет. Якщо збігів мало, колоду добирають іншими фільмами.
- Ключ задається змінною `OMDB_API_KEY`. У `server.js` вказано ключ за замовчуванням, щоб усе працювало одразу після клонування.
  Для публічного репозиторію краще прибрати його з коду й використовувати змінну середовища.
- Якщо OMDb недоступний, береться запасний список `data/movies.json` (українською, з емодзі замість постерів).
  У шапці гри видно джерело: «OMDb» або «запасний список ⚠️».

Дані й постери надає OMDb API (omdbapi.com).

## Структура

```
server.js              Express-сервер: каталог OMDb, жанри, кімнати, голоси, SSE
public/
  index.html           Розмітка (BEM-класи)
  app.js               Клієнтська логіка
  css/style.css        Точка входу: підключає base.css і всі блоки
  css/base.css         Змінні (світла/темна тема), базові стилі
  css/blocks/*.css     По одному файлу на BEM-блок
data/imdb-ids.json     IMDb ID фільмів каталогу
data/movies.json       Запасний список
```

## BEM

Класи в CSS і HTML іменуються за схемою `block__element--modifier`:
`card`, `card__stamp`, `card__stamp--yes`, `genre-chip--active`, `ranking__item` тощо.
Кожен блок лежить в окремому файлі `public/css/blocks/<block>.css`.
Stylelint відхилить клас, що не відповідає цій схемі. Стан екранів і елементів
перемикається модифікаторами (`screen--hidden`, `form__error--hidden`), а не окремими утилітами.

## API

| Метод | Шлях                      | Опис                                                  |
| ----- | ------------------------- | ----------------------------------------------------- |
| GET   | `/api/genres`             | Доступні жанри з кількістю фільмів                    |
| POST  | `/api/rooms`              | `{genres:[...]}` → створює кімнату, повертає `{code}` |
| POST  | `/api/rooms/:code/join`   | `{uid,name}` → колода, ваші відповіді, жанри кімнати  |
| POST  | `/api/rooms/:code/vote`   | `{uid,movieId,like}`                                  |
| GET   | `/api/rooms/:code/events` | SSE-потік з рейтингом наживо                          |

## Деплой

Render, Railway, Fly.io чи будь-який хостинг із Node.js ≥ 18 або Docker. Запуск: `npm start`. Змінні: `OMDB_API_KEY`, `PORT`.
Кімнати зберігаються в пам’яті й зникають після перезапуску сервера (для постійності замініть `rooms` на Redis чи базу).
